# Everest Textile OS — Virtual Factory Simulator

The **Virtual Factory Simulator** generates realistic, explicitly labelled operational events and telemetry for textile mill operations. 

> [!IMPORTANT]
> **Simulated Data Notice**: All operational events generated by this simulator explicitly carry `"source": "simulator"` to distinguish them from physical IoT sensors or real hardware.

---

## 1. Production Workflow

The simulator models configurable stages of textile manufacturing:
1. **Raw Material Preparation & Sizing**: Warp yarn preparation and stock allocation.
2. **Spinning**: Ring spinning and yarn cone production.
3. **Weaving / Knitting**: Interlacing yarn on air-jet looms into greige fabric.
4. **Dyeing & Finishing**: Coloration, stentering, and chemical treatment.
5. **Fabric Inspection**: 4-point grading and defect tracking.
6. **Roll Creation & Warehousing**: Packaging standard 100m fabric rolls.

---

## 2. Machine States

Virtual machines support five mutually exclusive states:
- `running`: Machine active and consuming materials / generating output.
- `idle`: Machine operational but unassigned or waiting for work.
- `setup`: Machine undergoing changeover or beam re-tying.
- `breakdown`: Unexpected stoppage (output is strictly 0.0).
- `maintenance`: Scheduled servicing or repair in progress.

---

## 3. Repeatable Scenarios

Five deterministic scenarios are selectable:
- **Scenario A (Normal Production)**: Standard smooth workflow without artificial disruptions.
- **Scenario B (Machine Breakdown)**: Active loom breakdown (`motor_fault`), halting an order mid-run.
- **Scenario C (Raw Material Shortage)**: High-priority order starved of yarn stock.
- **Scenario D (Quality Deterioration)**: Elevated defect multiplier producing quarantined rolls.
- **Scenario E (Urgent Customer Order)**: Rush order testing scheduling feasibility and line balancing.

---

## 4. Usage Example

```python
from simulator import scenario_b_machine_breakdown

sim = scenario_b_machine_breakdown(random_seed=42)

# Step the simulation forward by 30 minutes
events = sim.step(delta_minutes=30.0)

for evt in events:
    print(f"[{evt.timestamp.isoformat()}] {evt.event_type} - {evt.details}")
```
